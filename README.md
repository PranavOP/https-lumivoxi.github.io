# NEXUS GAMES

A futuristic browser-based mini-games website.

## Folder Structure
```
nexus-games/
├── index.html
├── css/style.css
├── js/script.js
├── games/
│   ├── snake.html
│   ├── breakout.html
│   ├── tictactoe.html
│   ├── minesweeper.html
│   └── 2048.html
└── README.md
```

## How to run
Open index.html in any browser. No server needed.

## Deploy to GitHub Pages
1. Push to a GitHub repo
2. Settings → Pages → source: main branch / root
3. Live at https://yourusername.github.io/nexus-games
